Connect the official Google Search Console API using read-only credentials. Verification alone does not authorize API access.

  1. Enable Search Console API in Google Cloud and create a service account.
  2. Grant its email access to the exact verified property in Search Console.
  3. In Vercel production environment variables, securely set GSC_CLIENT_EMAIL, GSC_PRIVATE_KEY and GSC_SITE_URL (for example https://mubestdigital.vercel.app/).
  4. Redeploy the site, then refresh this page. Do not paste the private key into chat or commit it to GitHub.
