ONE-TIME CONNECTION

Connect Vercel Web Analytics

Analytics is read directly from Vercel. Add the server-side access details in Vercel and the tracking script path below. Your access token is never stored in the browser or Neon.

1Enable Web Analytics in your Vercel project and redeploy.
2Add VERCEL_ANALYTICS_TOKEN and VERCEL_ANALYTICS_PROJECT_ID to Vercel Production environment variables. For a team project, also add VERCEL_ANALYTICS_TEAM_ID.
3Copy the static HTML tracking script path from Vercel's setup instructions and save it below. It looks like /your-unique-path/script.js.
This is a public script path, not your private Vercel access token.
